# GlobeHub ユーザーテスト 計画概要

> 作成日：2026-05-01　対象バージョン：Web版（開発環境）

---

## 1. テストの目的

| # | 目的 | 確認内容 |
|---|---|---|
| 1 | **操作性検証** | 旅記録の作成〜公開フローを初見ユーザーが迷わずに完走できるか |
| 2 | **AI機能評価** | 音声入力・AI整形・AIチャットが期待どおりに機能し、価値を感じてもらえるか |
| 3 | **UXボトルネック発見** | 離脱・混乱・誤操作が多い箇所を特定する |
| 4 | **KPI基準値の取得** | タスク完了率・操作時間をベースラインとして記録し、次回改善時と比較する |

---

## 2. テスト概要

| 項目 | 内容 |
|---|---|
| **形式** | モデレータ付きユーザビリティテスト（対面 or オンライン） |
| **参加者数** | 5〜8名（各属性2〜3名） |
| **所要時間** | 1人あたり 60〜75分 |
| **報酬** | Amazonギフト券 2,000円 相当 |
| **記録方法** | 画面録画 + 音声録音 + 観察メモ |

---

## 3. ターゲット参加者

### 属性グループ

| グループ | 条件 | 目標人数 |
|---|---|---|
| **A：旅好き非ユーザー** | 年に1回以上旅行する、旅行記録アプリ未使用 | 2〜3名 |
| **B：SNS投稿ユーザー** | Instagramなどで旅写真を投稿している | 2〜3名 |
| **C：AIツール経験者** | ChatGPT等のAIツールを日常的に使っている | 1〜2名 |

### 除外条件
- GlobeHubの開発・テストに関与している人
- モバイルアプリを普段使わない人（スマートフォン不所持）

### リクルート方法
1. 知人・友人への声かけ（優先）
2. テスター募集サービス（ユーザーテストドットコム、Lancers等）

---

## 4. 実施環境

| 項目 | 内容 |
|---|---|
| **デバイス** | テスト用スマートフォン（iPhone or Android）または参加者自身のデバイス |
| **ブラウザ** | Chrome（最新版）推奨 |
| **アクセス先** | ローカル開発サーバー（http://localhost:5000）または Vercel デプロイURL |
| **録画ツール** | Zoom（画面共有録画）または iPhone のミラーリング + QuickTime |
| **テストアカウント** | 事前に用意したデモアカウント（メールアドレス・パスワード別紙参照） |
| **マイク** | スポット音声入力テスト用に静かな環境を確保 |

---

## 6. 必要物品チェックリスト

**ファシリテーター側**
- [ ] テスト用デバイス（充電100%）
- [ ] 録画ツール起動・録画テスト済み
- [ ] 観察シート（人数分印刷 or デジタル）
- [ ] 事前・事後アンケート（Google Forms）リンク確認
- [ ] ストップウォッチ or タイマーアプリ
- [ ] テストアカウント認証情報（別紙）
- [ ] 同意書（個人情報保護・録音録画の同意）

**参加者側（当日案内するもの）**
- [ ] 参加同意書への署名
- [ ] 事前アンケート回答（5分）
- [ ] テストデバイスの貸し出しor接続設定

---

## 7. 倫理・個人情報

- 録音・録画は参加者の同意を得てから開始する
- 収集したデータはGlobeHub開発目的のみに使用する
- 参加者の氏名は記録せず、A・B・C…のコードで管理する
- テスト後30日以内に録画データを削除する

---

## 8. テスト後の分析・アウトプット

| アウトプット | 担当 | 期限 |
|---|---|---|
| 観察メモ整理・転記 | ファシリテーター | テスト翌日 |
| タスク完了率・時間の集計 | ファシリテーター | テスト翌日 |
| アンケート集計 | ファシリテーター | 2日後 |
| 動画の重要シーン切り出し | ファシリテーター | 3日後 |
| 改善提案レポート | チーム全員 | 1週間後 |
