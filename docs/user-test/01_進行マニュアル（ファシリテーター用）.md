# ファシリテーター進行マニュアル

> このマニュアルはテスト進行者（ファシリテーター）向けです。参加者には見せないでください。

---

## 事前準備チェックリスト（テスト30分前）

- [ ] 開発サーバーが起動している（`npm run dev` 実行済み）
- [ ] テストアカウントでログインできることを確認
- [ ] 録画ツール（Zoom / QuickTime）が正常動作している
- [ ] 画面録画の保存先フォルダを確認
- [ ] 観察シートを参加者コード（A〜H）ごとに用意
- [ ] ストップウォッチをリセット
- [ ] 静かな録音環境（マイクテスト済み）
- [ ] Google Forms の事前・事後アンケートのリンクを手元に用意
- [ ] 参加者の謝礼（Amazonギフト券コード）を手元に用意

---

## テスト開始スクリプト（読み上げ用）

> ※ 斜体は読み上げ文。通常文はファシリテーターへの補足。

---

### ① アイスブレイク（2分）

*「本日はお時間をいただきありがとうございます。GlobeHubという旅行記録アプリの使い勝手を確認するテストにご協力いただきます。」*

*「はじめに大切なことをお伝えします。これはあなたのスキルや知識をテストするものではありません。アプリの使いやすさを確認するテストですので、どんな感想も、操作に詰まった場面も、すべて私たちにとって貴重な情報です。」*

*「テスト中、思ったことや感じたことを声に出しながら操作してもらえると助かります。『なんか変だな』『ここ押していいのかな』など、独り言のように話しながら進めてください。」*

*「私はテスト中に口を挟まないようにしますが、タスクが終わったあとに質問をします。困ったことがあっても、できるだけご自身で解決しようとしてみてください。それも大切なデータになります。」*

---

### ② 同意書と録音録画の説明（2分）

*「録音と画面録画をさせていただきますが、よろしいでしょうか？得られたデータはアプリ改善のためだけに使用し、個人が特定できる形では公表しません。」*

→ 同意書にサインをもらう

---

### ③ 事前アンケート（5分）

*「まず、簡単なアンケートにご回答ください。」*

→ Google FormsのURLを渡す（02_事前アンケート）

---

### ④ アプリの説明（1分）

*「これからお使いいただくGlobeHubは、旅の思い出を記録して、他の旅人と共有できるアプリです。旅先でスポット（訪れた場所）を登録して、後で見返したり、次の旅の参考にしたりできます。AIが音声入力や旅行計画のサポートをしてくれる機能もあります。」*

*「では、実際に使っていただきましょう。タスクを一つずつお伝えしますので、順番にやってみてください。」*

---

## タスク進行の流れ

各タスクは次の手順で進めます：

1. タスク内容を口頭で読み上げる（タスクシートを見せてもよい）
2. ストップウォッチをスタート
3. 参加者が操作する（介入しない）
4. **完了 or 5分経過** でストップウォッチを止め、時間を観察シートに記録
5. 完了できなかった場合はヒントを出すか、次のタスクに進む
6. タスク間の感想を聞く（ミニインタビュー）

---

## 介入ガイドライン

| 状況 | 対応 |
|---|---|
| 参加者が3分以上同じ箇所で詰まっている | 「何か気になっていることはありますか？」と聞く |
| 参加者が明らかに誤った操作を繰り返している | 記録しつつ、5分たったらヒントを出す |
| 参加者が「もう無理」と言った場合 | 「ここまでで十分です、次に進みましょう」と伝える |
| 録画やシステムがクラッシュした場合 | 謝罪して再起動、時間は記録しない |

**絶対にやってはいけないこと：**
- 「ここを押してください」と直接誘導する
- 参加者の操作に対して評価・コメントする（「上手ですね」「あ、そこじゃないです」等）

## ヒントカード（タスクが詰まった場合のみ使用）

| タスク | ヒント1（穏やか） | ヒント2（具体的） |
|---|---|---|
| T1 アカウント登録 | 「右下のマイページを見てみてください」 | 「『新規登録』ボタンを探してみてください」 |
| T2 旅記録作成 | 「下のメニューで記録できる場所があります」 | 「鉛筆マーク（記録タブ）をタップしてみてください」 |
| T3 スポット追加 | 「旅記録を開いた画面を探してみてください」 | 「『スポットを追加』ボタンがあります」 |
| T4 音声入力 | 「マイクマークを探してみてください」 | 「メモ欄の右上にマイクボタンがあります」 |
| T5 AI整形 | 「メモを入力したあと、何かボタンが出ていませんか？」 | 「✨マークのボタンを押してみてください」 |
| T6 旅行計画 | 「ホーム画面に旅行計画のボタンがあります」 | 「『AI旅行計画』カードをタップしてください」 |
| T7 AIチャット | 「下のメニューに✨マークがあります」 | 「『AI』タブをタップしてください」 |

## 各タスク後のミニインタビュー質問（30秒〜1分）

- 「今の操作、いかがでしたか？」
- 「詰まったところはありましたか？それはなぜですか？」
- 「期待通りの動作でしたか？」

---

## テスト終了スクリプト

*「お疲れ様でした。全タスクが終わりました。最後に少し感想を聞かせていただいていいですか？」*

→ 05_インタビュー質問 を実施（10分）

→ 事後アンケートのURLを渡す（04_事後アンケート）

*「大変参考になりました。ありがとうございました。こちらが謝礼のギフト券です。」*

→ Amazonギフト券コードを渡す

---

## 録画終了・データ保存

- [ ] 録画を停止する
- [ ] ファイル名を「YYYYMMDD_参加者コード（例：A）」に変更
- [ ] 観察シートのデータを転記・保存
- [ ] 次の参加者のためにアプリをリセット（テストアカウントでログアウト）
