## テスト後の分析ステップ

### Step 1：当日夜（テスト終了後30分以内）
- [ ] 観察シートのメモをデジタル化（Notion or Google Sheets）
- [ ] 「今日の気づき3つ」をSlackや社内チャンネルに共有

### Step 2：翌日
- [ ] 全参加者のタスク完了率・所要時間を集計（06_KPI シートに転記）
- [ ] アンケート結果をGoogle Sheetsにまとめる

### Step 3：2〜3日後
- [ ] 録画の重要シーンに時刻タグをつける
- [ ] 参加者の発言を「良かった点」「悪かった点」「要望」に分類
- [ ] Severity別の問題リストを作成（06_KPI > 優先改善マトリクス）

### Step 4：1週間後
- [ ] 改善提案レポートをまとめる（改善案と対応優先度）
- [ ] 次回テスト予定の設定

---

## 結果報告の構成（改善提案レポート）

1. **テスト概要**（参加者数・実施日・環境）
2. **KPI達成状況**（定量サマリー）
3. **主要な発見**（良い点3つ・問題点5つ程度）
4. **問題一覧**（Severity 1〜4 の表）
5. **改善提案**（優先度付き）
6. **参加者の生の声**（印象的な発言の抜粋）
7. **次のアクション**（誰が・何を・いつまでに）
